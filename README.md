# Jellyfin plugin repository

Plugin repository for Jellyfin with the plugins below. Add it in **Dashboard → Plugins → Repositories**:

```
https://raw.githubusercontent.com/ApenasAngelo/jellyfin-plugins/main/manifest.json
```

| Plugin | What it is |
|---|---|
| [Home Screen Sections Encore](https://github.com/ApenasAngelo/jellyfin-plugin-home-sections-encore) | Fork of [Home Screen Sections](https://github.com/IAmParadox27/jellyfin-plugin-home-sections) for Jellyfin 12.4 |
| [Media Bar Encore](https://github.com/ApenasAngelo/jellyfin-plugin-media-bar-encore) | Fork of [Media Bar Enhanced](https://github.com/CodeDevMLH/jellyfin-plugin-media-bar-enhanced) |
| [Fin Tweaks](https://github.com/ApenasAngelo/jellyfin-plugin-fin-tweaks) | Small web client tweaks, each with a switch in the admin page |

The plugins need [File Transformation](https://github.com/IAmParadox27/jellyfin-plugin-file-transformation).

## How it is built

`manifest.json` is generated by `generate.py` from the GitHub releases of the repositories in `plugins.json`
(each release carries one zip with a `meta.json`). The `Update manifest` workflow runs it every hour and on demand.
